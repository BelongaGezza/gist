GIST — Third-Party Notices
===========================

GIST itself is licensed under the MIT License (see the "View source on
GitHub" link in Settings -> About).

GIST's Rust core (crates/, compiled into GistCore.xcframework and statically
linked into this app -- this app has no other third-party dependencies: no
Swift Package Manager packages, no CocoaPods, no vendored SDKs) depends on
the following third-party Rust crates. Every license below was cross-checked
against this project's license allow-list (MIT, Apache-2.0, Apache-2.0 WITH
LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0, MPL-2.0,
CDLA-Permissive-2.0) via `cargo deny check licenses`, which passes clean.

See docs/THIRD-PARTY.md in the GIST source repository for the full
methodology, per-platform breakdown (this list covers the shared Rust core
only), and the Windows app's separate NuGet dependency list.
